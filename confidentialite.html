Politique de confidentialité

Cette politique décrit le prototype personnel local Engagement, exploité par Ohini Bruce, joignable à ohinibruce@gmail.com.

Données et finalités

Le prototype utilise les contrats, inventaires, rapports, factures et compléments sélectionnés pour suivre leurs obligations et conserver les preuves. Pour Gmail, il utilise l’adresse du compte autorisé, les identifiants de messages et de fils, leurs en-têtes et le contenu des échanges de test nécessaires au rapprochement.

Autorisations Gmail

Les droits demandés sont gmail.readonly et gmail.send : Google permet ainsi la lecture de la boîte et l’envoi d’e-mails. L’implémentation actuelle filtre les recherches sur les fils de test identifiés par Engagement et limite les destinataires à la propre adresse du titulaire. Elle ne demande pas le droit de supprimer les messages.

Stockage et accès

Les identifiants OAuth et jetons sont chiffrés localement avec Windows DPAPI, sous le compte Windows du propriétaire. Les messages utiles, pièces et journaux sont conservés dans les dossiers locaux du prototype ; ils ne bénéficient pas tous de ce chiffrement applicatif. Le dossier de travail étant situé dans OneDrive, une synchronisation peut avoir lieu selon les réglages OneDrive du propriétaire.

Ces données ne sont pas publiées sur le présent site GitHub Pages. Google traite les échanges via Gmail. Le prototype est réservé à son propriétaire ; il ne fournit aucun portail public d’accès à ces données.

Intelligence artificielle et partage

Des rapports sélectionnés peuvent être transmis à Gemini dans les parcours de lecture IA configurés séparément. Le contenu Gmail n’est pas automatiquement transmis à Gemini par le transport Gmail actuel : les confirmations de date y sont contrôlées localement. Toute évolution de cette pratique devra être décrite avant son activation.

Les données reçues des API Google ne sont ni vendues, ni utilisées pour de la publicité, ni employées pour entraîner un modèle généraliste. L’utilisation des informations reçues des API Google respecte la Google API Services User Data Policy, y compris ses exigences de Limited Use.

Conservation, suppression et révocation

Les preuves et journaux sont conservés jusqu’à leur suppression par le propriétaire pour les besoins du test et de son audit ; aucune purge automatique n’est actuellement configurée. Le propriétaire peut arrêter le serveur et supprimer les dossiers de test, les jetons locaux et, le cas échéant, leurs copies et sauvegardes synchronisées. La suppression locale ne supprime pas les messages déjà présents dans Gmail.

L’accès peut être révoqué dans les connexions du compte Google. Cela arrête les futurs accès mais ne supprime pas les archives déjà enregistrées. Pour toute question ou demande concernant les données : ohinibruce@gmail.com.

Visiteurs de ce site

Ces pages statiques n’intègrent ni formulaire, ni mesure d’audience ajoutée, ni publicité. L’hébergeur GitHub peut traiter des données techniques de navigation conformément à sa politique de confidentialité.
